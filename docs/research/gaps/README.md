# 报告 gap 归档

这里按核验日期保存每次报告相对基线的变化。研究正文负责表达当前结论，gap 负责解释这次结论如何变化。

执行方法见[报告更新流程](../UPDATE-WORKFLOW.md)，任务入口见[AGENTS.md](../../../AGENTS.md)。

## 目录规则

- 日期按 Asia/Shanghai，使用 `YYYY-MM-DD/`。
- 每次完整更新使用一个 `NN/` 批次，从 `01` 开始。
- 同日后续批次追加 `02/`、`03/`，不覆盖旧批次。
- 每个批次保留变化说明、manifest 和三份逐行 diff。
- 已归档批次保持原样；事实修正另开批次。
- 总索引和日期索引允许追加。补归档须写明原报告提交。
