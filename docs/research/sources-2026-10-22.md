# Personal Agent 调研来源索引与核验记录

核验日期：**2026-10-22（Asia/Shanghai）**。

对应正文：[Personal Agent 深度调研](personal-agent-landscape-2026-10-22.md)。正文沿用 S01–S48 的商业与背景来源，新增 R01–R32 为同类开源应用的文档与关键源码。编号表示来源身份，不表示质量评分。网页可能继续更新；本次没有在仓库镜像保存商业网站全文。

## 1. 核验方法

1. 先按用户给出的名称检索，使用官方域名、产品公告和交叉链接确认身份。
2. 商业能力与套餐优先采用官方产品页、帮助中心、研究博客及更新日志。OpenAI 部分先通过 OpenAI Docs 检索和读取官方文档，再核对相关产品指南。
3. 开源部分通过 GitHub 读取 README、项目元数据与相关许可证；记录默认分支提交，并在固定提交处重新读取。补充研究抽查后台 worker、Agent 循环、审批、模型/托管 provider 等关键代码。没有安装这些项目或审计完整实现。
4. 搜索摘要用于发现入口；正文中的关键能力、限制和价格以实际打开或读取的来源为依据。
5. 未取得产品统一测试日志，未比较真实活跃用户、收入或留存。未将厂商跑分、融资消息、下载量或 Star 数变成能力排名。

证据强度需分开理解：官方说明可以确认厂商公开承诺或描述了某机制；仓库文档可以确认维护者描述了某设计；两者都不足以独立证明实际任务成功率、安全效果或长期用户收益。

## 6. 未采用为结论依据的资料

检索过程还遇到产品聚合站、社交帖子、第三方对比与媒体评测。这些可以帮助发现关键词，但未用于建立产品能力排名、成功率、融资估值或真实配置结论。尤其没有采用以下推断：

- 由 Agent 自报 CPU、内存或模型名推断真实基础设施。
- 由下载、点赞、Star、融资或估值推断产品效果。
- 由替换过模型的重建 runtime 成绩推断真实消费产品的端到端表现。
- 由一次成功演示推断任务可长期无人看管。
- 由未检索到某项功能推断产品一定不支持。

公开页面可读性也有差异：部分主页重定向到登录、旧文档域名失效、搜索摘要可能滞后。因此本研究保留查询日期、固定源码引用和待验证项；未来更新应按具体产品和版本重新核验。

## 7. 后续更新记录模板

每次更新建议保留：核验日期、产品/版本、原始来源、变化内容、影响的正文段落，以及是否实际测试。若产生实测结果，另记录账户计划、地区、模型、工具配置、任务样本、失败日志与成本口径，避免与本版公开资料研究混在一起。

### 8.4 对结论影响最大的核验结果

- **有产品界面不等于持续个人 Agent。** Anil 版 Open Grok Bot 的 README 明确没有长期记忆、routine 和后台 worker；静态 Open Muse 明确标签页关闭后停止。
- **应用开源不等于运行后端全部开放。** chyroc 使用 MA，SiliconLabAI 使用 Manus；CopilotKit 模板的 Intelligence 也有额外服务和许可条件。
- **模拟与真实验证必须拆开。** CopilotKit OpenMuse 的录屏使用 AI Mock 和虚构邮箱，同时调用真实 Chromium；不能由该录屏推导真实个人邮箱的自动任务能力。
- **审批界面不等于强制执行边界。** wolfqing 的安全文档明确保留这一限制；OpenBot 的策略引擎行为也要与实际启动配置分开。
- **代码存在不等于已经跑通。** worker/lease/provider/审批源码可以提高对“有实现”的判断把握，仍不替代真实服务和任务验证。
- **源码公开不等于许可明确。** 对未见根许可的项目保留事实，不直接列为可无条件复用的开源成品。
